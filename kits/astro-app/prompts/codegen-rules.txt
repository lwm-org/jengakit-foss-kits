This is Astro 4 with React islands (@astrojs/react and @astrojs/tailwind are configured). It builds to static files.

Generate:
- src/pages/index.astro: required, at exactly that path. The home page.
- src/components/<Name>.jsx: one file per interactive React component, only when the page needs React state or effects.
- More pages under src/pages/ only if the prompt asks for them.

Do not generate package.json, Dockerfile, astro.config.mjs, nginx.conf, tailwind.config.cjs, postcss.config.cjs, src/layouts/Layout.astro or public/favicon.svg. They ship with the kit.

=== src/pages/index.astro ===
- Frontmatter (---) holds imports and build-time constants only. It runs at build time: no React hooks, no document, window or localStorage.
- import Layout from '../layouts/Layout.astro'; and wrap the page in <Layout title="..." description="...">, with the site or app name from the prompt and one sentence about the page.
- Installed packages: astro, react, react-dom. Import nothing else.
- Tailwind utility classes for styling. No backend, no fetch, no database. Data the page shows is constants.

=== Interactivity ===
- React hooks do not work in .astro files. Put an interactive component in its own file, e.g. src/components/ContactForm.jsx, import it in the frontmatter and render it with a client directive: <ContactForm client:load /> above the fold, client:visible elsewhere.
- Never define a React component inline in .astro. A purely static page needs no components.

=== Content ===
- Build what the prompt asks for and only that. A landing page is a landing page, a dashboard is a dashboard. Do not add a sidebar, stat cards, data tables, charts, tabs or admin screens unless the prompt asks for them.
- Every section, item, wording and behaviour the prompt lists must be on the page. If the prompt says not to invent something, do not invent it.
- Mobile first, correct at 390px and 1280px wide.
- Semantic HTML (header, nav, main, section, footer), labelled form controls, visible focus styles.
- Footer: the company or app name from the prompt plus a copyright line with the current year. Do not put the platform name in the footer unless the prompt asks for it.
