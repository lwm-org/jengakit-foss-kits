INFRA RULES for lobster kit:

DOCKERFILE:
- Base: node:20-slim
- Install build deps: RUN apt-get update && apt-get install -y python3 make g++ curl && rm -rf /var/lib/apt/lists/*
- WORKDIR /app
- COPY package*.json ./
- RUN npm ci --omit=dev
- COPY . .
- RUN mkdir -p /data
- EXPOSE 3000
- HEALTHCHECK --interval=30s --timeout=10s --start-period=30s CMD curl -f http://localhost:3000/health || exit 1
- CMD ["node", "server.js"]

CONTAINER:
- One running instance
- Port 3000
- Ready check: HTTP GET /health on port 3000, first check after 20 seconds
- Alive check: HTTP GET /health on port 3000, first check after 30 seconds
- Resources: reserve 0.25 CPU and 256 MiB memory, cap at 0.5 CPU and 512 MiB memory
- Publish port 3000 (container port 3000)
- Standard public route

ENV VARS to pass through:
- JENGAKIT_LLM_URL (from system)
- JENGAKIT_LLM_TOKEN (from system)
- LOBSTER_ADMIN_PASSWORD
- LOBSTER_TELEGRAM_BOT_TOKEN
- LOBSTER_DISCORD_BOT_TOKEN
- DEPLOY_LLM_API_KEY
- DB_PATH=/data/lobster.db
- NODE_ENV=production
