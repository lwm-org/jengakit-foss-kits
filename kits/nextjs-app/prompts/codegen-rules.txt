Generate exactly these two files, at exactly these paths, and nothing else:
1. app/page.jsx: the whole application UI as one React component
2. app/globals.css: Tailwind directives plus the theme CSS

Do not generate package.json, Dockerfile, next.config.js, app/layout.jsx, jsconfig.json, tailwind.config.js, postcss.config.js or any other file. They ship with the kit.

=== app/page.jsx ===
- First line, exactly (double quotes): "use client";
- One default export: export default function Home() { ... }
- All logic lives in this one component. Use useState for interactive state (open menu, form fields, validation messages, active view).
- Installed packages: react, lucide-react, recharts, tailwindcss. Import only what the page uses. Import nothing else.
- There is no backend. No fetch, no API routes, no database. Data the page shows is constants in this file.
- Build what the prompt asks for and only that. A landing page is a landing page, a dashboard is a dashboard, a store is a store. Do not add a sidebar, stat cards, data tables, charts, tabs or admin screens unless the prompt asks for them.
- Every section, item, wording and behaviour the prompt lists must be on the page. If the prompt says to include something, include it. If the prompt says not to invent something, do not invent it.
- Mobile first, Tailwind utility classes only, correct at 390px and 1280px wide.
- Semantic HTML (header, nav, main, section, footer), labelled form controls, visible focus styles.
- Page metadata: the layout does not know the page's name. In a useEffect, set document.title to the site or app name from the prompt and set the meta description (create the tag if missing) to one sentence about the page.
- Footer: the company or app name from the prompt plus a copyright line with the current year. Do not put the platform name in the footer unless the prompt asks for it.

=== app/globals.css ===
Must start with:
@tailwind base;
@tailwind components;
@tailwind utilities;

Then CSS variables on :root for the palette the prompt asks for, and any custom styles the page needs.
