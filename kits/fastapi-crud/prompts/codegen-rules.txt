This app has a WORKING BACKEND with a universal CRUD API and SQLite database.
Data PERSISTS across page refreshes. Do NOT hardcode sample data.

=== API ENDPOINTS (provided by template) ===

  GET    /api/{table}         → returns JSON array of all rows
  POST   /api/{table}         → creates row (JSON body), returns {id, ...fields}
  PUT    /api/{table}/{id}    → updates row by id (JSON body with fields to update)
  DELETE /api/{table}/{id}    → deletes row by id

Tables: /api/invoices, /api/customers, /api/payments, etc.

=== index.html RULES ===

1. Single HTML file with inline <script> tag — no modules, no imports

3. Use Lucide icons via CDN: <script src="https://unpkg.com/lucide@latest"></script>
4. Call lucide.createIcons() after DOM loads
